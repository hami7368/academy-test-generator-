How to fill the sheet

ColumnWhat to write
ClassExactly as in the app, e.g. Class 9th
SubjectExactly as in the app, e.g. Physics
ChapterChapter name, e.g. Physical Quantities and Measurement. If it does not exist yet, it will be created automatically.
Chapter NoChapter number, e.g. 1 (only used when a new chapter is created)
TypeMCQ, Short, Long or Numerical
SourceTheory or Exercise — this is how papers keep them separate
DifficultyEasy, Medium or Hard (blank = Medium)
MarksNumber, e.g. 1 (blank = 1)
QuestionThe full question text
Option A – DOnly for MCQ — all 4 options are required
Correct OptionOnly for MCQ — A, B, C or D
AnswerAnswer / solution (shown in the answer key)
